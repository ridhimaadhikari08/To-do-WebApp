# To-do-WebApp
A clean, light-weight To-Do web app built with Python and Django. This app helps users easily create, update, organize, and manage daily tasks through a modern user interface.

Key Features:- 
- Create Tasks: Quickly add new tasks to your list.
- Inline Editing: Edit existing task names on the fly without refreshing or navigating away.
- Delete Tasks: Remove individual completed tasks or use **Clear All** to reset your entire list.
- Task Counter: Live tracker showing the total count of pending tasks.
- Responsive UI: Styled card design featuring custom CSS background styling.
- Secure Backend: Implements Django's ORM and built-in CSRF protection for safe form submissions.

Tech Stack

- Backend: Python, Django
- Frontend: HTML5, CSS3, JavaScript
- Database: SQLite (default Django DB)
